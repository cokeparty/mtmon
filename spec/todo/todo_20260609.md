[DML 모니터링]
1. 담당자 화면 - 전체 그룹 목록에서 그룹 ID는 의미가 없으니 위에부터 번호로 1번부터 순서대로 출력할 것.

2. 담당자 화면 - SR번호 오른쪽 칼럼에는 SR에 대한 정보 칼럼이 나와야 될 것 같은데(SR번호, SR제목, 작업구분, 작업승인일, SR종료일) -> SR DB에 정보있음, 상단에 자동매핑 버튼을 누르면 SR번호에 해당하는 내용을 자동으로 채워야 한다.

3. 담당자 화면 - 개발자별 진행 현황에 개발자가 안나온다. (개발자명은 DB에 dml.dml_log 테이블에 db_user 칼럼에 들어가있다.), 그리고 개발자별로 진행률이 나와야 한다.

4. 담당자 화면 - 엑셀 추출 기능 추가

5. 담당자 화면 - 엑셀 출력 시 [명령어	요청 시각	접속계정	사용자명	SR번호	SR제목	작업구분	작업승인일	SR종료일	검증결과] 칼럼으로 나와야 함.

[DDL 모니터링]

1. 엑셀 다운로드 기능 구현

2. DDL도 DML과 마찬가지로 오른쪽에 (SR번호, SR제목, 작업구분, 작업승인일, SR종료일) -> SR DB에 정보있음 칼럼이 추가되어야 한다.

3. DML과 마찬가지로 업무명별로 CSV 업로드 제한이 걸려야 한다.

4. 자동매핑 클릭 시 SR번호가 매핑되어 있으면 그 이후의 내용을 자동으로 매핑해야 한다. (spec/DML/sr_enrich_v1.9.py 참고 )

5. DDL의 경우 ddl.ddl_log 테이블 1개만 있는데 더 필요한 거 있으면 위의 1,2,3,4번 구현하는데 필요한 게 있다면 spec/db_change_sql.md 에 쿼리문 추가해줘. 필수적인 것만 있으면되니까 필요없으면 추가안해도돼.
