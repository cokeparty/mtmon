[DDL]
1. DDL 모니터링에서 SR번호를 적용했는데도 불구하고, 윗 부분에 미적용으로 나오는 문제해결 필요

[부서이동자]
1. 부서이동자 일간 모니터링 화면에서 (전체,퇴직자,부서변경자,HR권한,전자조달권한,PMS권한 탭) SR번호를 저장하면 
SR DB에서 SR번호가 존재하는지 확인하고
존재하면 -> DML 개발자화면(templates/dml_developer.html)과 같이 입력창 초록색, 오른쪽에 초록색 글씨로 매핑됨 표시
존재하지않으면 -> 입력창 빨간색, 오른쪽에 빨간색 글씨로 매핑됨 표시

2. 부서이동자 일간 모니터링 HR권한, 전자조달권한, PMS권한 탭에서 칼럼에 권한등록일, 권한회수일 등이 존재해야함. 
구체적으로 각각의 출력되는 칼럼은 아래와 같음.
HR - [구분, 부서변경일	부서명	사번	이름	이전부서명	responsibility	권한시작일	권한부여일	마지막 권한 사용일	이전부서명]
전자조달 - [구분, 부서변경일	부여권한	role_cd	사번	이름	권한 등록일	부서명	이전부서명]
PMS - [구분, 부서변경일	부여권한	role_cd	사번	이름	권한 등록일	부서명	이전부서명]

부여권한 = role_name
role_cd = role_code
사번 = empno
이름 = emp_name
구분 = system_code

3. 부서이동자 일간 모니터링에서 처리 칼럼에 미처리 희미한 색으로 되어있는 건 뭐지?
