[프로그램변경]
1. 모니터링결과 칼럼은 한줄로만 나오게하여 행 높이가 높아지지 않게 해야한다. 너무길면 타이틀로 마우스올렸을 때 확인가능하게 해야한다.
2. 입력 필드 입력 시 변경되었다는 메시지가 떠야함.(부서이동자 화면참고)
2. (프로그램 변경요청승인, 사용자테스트, 이관전 승인, 개발자, 이관자, 검토수행자) 칼럼 내용을 수정했을 때 변경되었다는 것을 알 수 없음. 미입력 시 지금 색 유지하고, 입력(또는 디폴트값으로 채워진경우)행 배경색과 같은 색으로 변경(비정상 행의 경우는 노란색)함.
3. 파일명 내용을 한 줄로 끝까지 볼 수 있도록 나오게 변경(현재는 짤려서 나오는데 중요한 정보이므로 다 조회되도록)
4. 모니터링결과 칼럼에서 비정상인 경우에는 사유를 작성했다면 그 사유가 나와야 하고, 작성하지 않았다면 사유 작성이 필요하다는 내용이 있어야함. 현재는 NFS 매핑 실패 - SR번호 없음 으로 나옴. 미적용인 경우에는 SR번호 없음 으로 나와야함. -> 엑셀도 동일하게
