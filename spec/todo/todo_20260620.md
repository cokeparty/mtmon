[프로그램 변경 리스트]
1. 프로그램 변경 리스트 화면(templates/program_change.html)에서 전체 건수 조회할 수 있게 수정.
2. 프로그램 변경 리스트(templates/program_change.html) 회차 선택할 때 데이터가 있는 회차를 조회하고나서 없는 회차 선택 시 "선택한 회차의 적재 데이터가 없습니다." 나오고 아래에 이전에 조회했었던 내용이 출력됨. -> 없는 회차 선택 시 아래에 이전에 조회했던 내용이 나오는 것은 불필요함.
3. 소스파일명, SR번호 등 필터가 조회버튼 클릭하지 않으면 안보이고 셀렉트 박스 전체/적용/비정상/미적용만 즉시 필터링됨. => 조회버튼 클릭 없이도 소스파일명, SR번호, SR제목, 이관시각 등으로 필터링 가능하게.
4. 화면 접속 시 전월로 조회될 것.(현재가 6월이면 5월 자료 출력)
