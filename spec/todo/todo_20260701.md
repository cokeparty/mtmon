[로그]
1. 콘솔로그에 너무 많은 로그가 찍힘. 그리고 너무 지저분함. 예를들어 파일명을 전부 출력하거나 SR번호를 출력하는데, 완료되었는지 실패했는지나 IP PORT 등 빠른 조치를 위해 필요한 내용만 존재해야함.
2. logs/app/application 로그에 너무 적은 로그가 찍힘. SR을 입력하면 어떤 DB에 들어가서 어떤 정보를 가져와 어디에 적재하는지를 알아야하지. 현재는 reload 변경 로그만 존재하고 다른 로그는 존재하지 않음. 실제로 데이터가 어떤 흐름으로 실행되는지 조금 더 상세한 로그가 필요함. reload 변경 로그는 불필요함. 용량이 너무 많을 것 같다면, debug모드 info모드 구분해서 설정할 수 있게해주고 어디서 바꿔야하는지 알려주렴.
3. 로그출력 시 A서버, B서버 이런식으로 적혀있는게 있는데 FTP서버, NFS서버 이런식으로 구체적으로 적어야함.
