파일구조도 spec/dml/file_structure.md
1. 엑셀 출력 시 웹에서는 조회되는 비정상 행이 없음. 아마도 엑셀에서는 작업승인일이 없는 경우 판정불가로 표시하는 것 같은데 웹상에서 정상, 비정상의 경우에는 검증결과에도 정상 비정상이 떠야함. (DDL 모니터링도 그렇게 돼있는지 확인해서 그렇다면 그것도 수정)
2. 개발자화면에서 비DML로 버튼 클릭 시 새로고침되는데 SR번호 적용할 때와 같이 새로고침이 없어야 됨.
3. 웹 SR번호 칼럼에서 "DML이 아님" 표시가 상태 칼럼 디자인과 같은데 SR번호 입력창 그대로 유지하고 SR번호가 입력된 것처럼 표시하는게 좋을 것 같음(SR번호 칼럼 디자인 일관성 유지. 당연히 비DML인 경우는 입력창 비활성화해서 입력창에서는 수정안되게해야된다.). 그리고 SR번호, SR제목, 작업구분, 작업승인일, SR종료일 전부 DML이 아님 표시를 해야됨. (작업구분칼럼처럼 텍스트로) 마지막으로 엑셀에도 DML이 아닌 경우, DML이 아님 표시가 SR번호 ~ SR종료일까지 적혀있어야함.
4. 개발자화면에서도 비정상 사유를 적은 것과 적지 않은 것을 구분할 수 있어야함.(담당자화면참고)
